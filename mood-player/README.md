# Mood Player — Apple Music для ПК, который сам подбирает музыку

Запускаешь, играешь в Доту или занимаешься своими делами, а музыка идёт сама:
подбирается под тебя и под настроение. Песню, которая не нравится, можно удалить навсегда, и она больше не попадётся.

## Что умеет

- **Твой аккаунт Apple Music:** полные треки по твоей подписке.
- **Автоподбор под тебя.** Плеер смешивает твою медиатеку, недавно прослушанное, «тяжёлую ротацию»,
  персональные рекомендации Apple и тематические плейлисты Apple Music под настроение.
  Исполнители, которых ты уже слушаешь, получают приоритет.
- **Настроение:** Игра, Фокус, Чилл, Энергия, Весело, Грусть, Ночь, а также режим **«Авто»**:
  - когда запущена Dota 2 (или CS2, Valorant, LoL), включается игровая музыка;
  - в остальное время настроение выбирается по времени суток.
- **Ползунок «Знакомое ↔ Новое»** задаёт, сколько в очереди будет любимого, а сколько нового.
- **🚫 Удалить навсегда.** Песня попадает в чёрный список (файл `data.json`) и получает «дизлайк» в самом Apple Music,
  чтобы Apple тоже меньше её предлагала. Можно запретить и **исполнителя целиком**. Если удалил по ошибке,
  песню можно вернуть из списка «Удалённые песни».
- **Учится на пропусках.** Песни, которые ты быстро пропускаешь, звучат реже. После 3 быстрых пропусков песня перестаёт попадаться.
  Песни с **♥** звучат чаще.
- **Горячие клавиши работают прямо в игре:**

  | Клавиши | Действие |
  |---|---|
  | `Ctrl+Alt+End` | удалить песню навсегда |
  | `Ctrl+Alt+PageDown` | следующая |
  | `Ctrl+Alt+Home` | пауза / играть |
  | `Ctrl+Alt+Insert` | нравится ♥ |
  | `Ctrl+Alt+PageUp` | сменить настроение |

  Каждое нажатие подтверждается тихим коротким сигналом, так что окно открывать не нужно.
  Медиаклавиши клавиатуры тоже работают.

## Почему грузит систему по минимуму

- Сам плеер — один `.exe` на Go без установки. В фоне он только раз в 15 секунд проверяет, запущена ли игра.
- Звук проигрывается в маленьком окне Edge, который уже есть в Windows (отдельный браузер не нужен).
  Окно запускается урезанным: без расширений, синхронизации, фоновых обновлений и лишних панелей Edge.
- Интерфейс без анимаций. Пока окно свёрнуто, полоса прогресса не перерисовывается.
- Медиатека кэшируется на сутки, поэтому лишних запросов к Apple нет.
- Закрыл окно — программа полностью выходит, в фоне ничего не остаётся.

## Установка

1. Скачай `MoodPlayer.exe` и положи в отдельную папку, например `C:\MoodPlayer\`.
   В этой папке будут лежать настройки и чёрный список.
2. Запусти. Если Windows покажет «Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**
   (программа без платной цифровой подписи).
3. При первом запуске откроется экран **«Настройка»**. Введи ключ Apple (см. ниже), один раз.
4. Нажми **«Войти в Apple Music»** и войди в свой Apple ID. Вход запоминается.

Собрать exe самому: установи Go 1.22+ и запусти `build.bat` (или `./build.sh`).

## Ключ Apple (developer token) — один раз

Apple пускает сторонние плееры к Apple Music только через официальный MusicKit, а для него нужен ключ разработчика.
Обойти это легально нельзя. Ключ требует **платного аккаунта Apple Developer Program ($99 в год)**.

1. Вступи в Apple Developer Program на <https://developer.apple.com/programs/>.
2. **Team ID** указан на <https://developer.apple.com/account> в разделе *Membership details* (10 символов).
3. Открой **Certificates, Identifiers & Profiles → Identifiers → «+» → Media IDs**, введи любое описание и
   идентификатор (например `media.com.yourname.moodplayer`), отметь **MusicKit**, нажми *Register*.
4. Открой **Keys → «+»**, введи имя (например `MoodPlayer`), отметь **Media Services (MusicKit, ShazamKit…)**,
   нажми *Configure*, выбери Media ID из шага 3, затем *Continue → Register*.
5. Скачай файл **`AuthKey_XXXXXXXXXX.p8`** (скачать его можно только один раз!) и запиши **Key ID**.
6. В плеере на экране «Настройка» введи Team ID и Key ID, выбери файл `.p8` и нажми «Сохранить».

Ключ хранится только у тебя на ПК (`AuthKey.p8` рядом с exe) и никуда не отправляется.
Плеер сам делает из него токен, а Apple видит только токен.

## Файлы рядом с exe

| Файл | Что это |
|---|---|
| `config.json` | настройки (Team ID, Key ID, порт, список игр, хоткеи вкл/выкл) |
| `AuthKey.p8` | твой ключ Apple, **никому не отправляй** |
| `data.json` | чёрный список, ♥, пропуски, выбранное настроение |
| `edge-profile\` | профиль окна плеера (здесь запоминается вход в Apple ID) |
| `moodplayer.log` | лог на случай проблем |

### Тонкая настройка `config.json`

```json
{
  "port": 47823,
  "hotkeys": true,
  "gameProcesses": ["dota2.exe", "cs2.exe", "valorant.exe", "leagueclient.exe"]
}
```

Если какая-то комбинация клавиш занята другой программой, это будет видно в `moodplayer.log`.
Запросы и жанры для каждого настроения лежат в `web/moods.js`. После их правки exe нужно пересобрать.

## Если что-то не так

- **«MusicKit не загрузился»:** нет интернета, или `js-cdn.music.apple.com` блокируется (VPN/антивирус).
- **Не играет звук или ошибка DRM:** обнови Microsoft Edge. Плееру нужен Edge (или Chrome) с поддержкой Widevine.
- **Хочу сбросить вход в Apple ID:** удали папку `edge-profile`.
- **Хочу начать подбор с нуля:** удали `data.json` (чёрный список тоже удалится!).
