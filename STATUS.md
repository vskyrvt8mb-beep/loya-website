# Loya Website — состояние

Статичный сайт (без сборки) + serverless-функции Vercel для оплаты.

## Файлы
- `index.html` — продающая главная: герой с настоящими экранами программы, ниши, проблемы → решение,
  «Запуск за 10 минут», тур по программе (вкладки со скриншотами), 9 возможностей, калькулятор
  выручки, цена с формой оформления прямо на странице, FAQ, финальный призыв, футер.
- `pricing.html` — отдельная страница оформления (на неё Stripe возвращает при отмене).
- `success.html` — после оплаты: 3 шага (скачать → вставить ключ → готово), ключ с кнопкой
  «Копировать»; ключ запрашивается повторно несколько раз, пока вебхук Stripe его создаёт.
- `style.css` — единый стиль всех страниц (графит + золото, как в приложении).
- `i18n.js` — все тексты на 4 языках (ru / uk / sk / en). `site.js` — язык, анимации, тур,
  калькулятор, оформление подписки, ссылка «Скачать».
- `img/*.webp` — настоящие скриншоты программы на каждом языке (dashboard, scan, marketing, clients, analytics).
- `logo.png`, `favicon.png`, `favicon.ico`, `apple-touch-icon.png`, `og-image.png` (превью для соцсетей).
- `api/` — Stripe + Supabase (без изменений, кроме: язык передаётся в success/cancel ссылки).

## Язык
Определяется так: `?lang=` в ссылке → сохранённый выбор → язык браузера (cs → sk) → en.

## Кнопка «Скачать для Windows»
Сама берёт установщик `.exe` из последнего релиза GitHub `vskyrvt8mb-beep/loya-website`
(через GitHub API). Если API недоступен — ведёт на страницу последнего релиза.
Новую версию программы достаточно опубликовать релизом на GitHub — сайт менять не нужно.
