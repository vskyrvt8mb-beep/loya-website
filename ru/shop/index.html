Частые вопросы

Подойдёт ли для магазина одежды, косметики или цветов?

Да. Loya подходит для любой розницы, где покупатели возвращаются: одежда, косметика, цветы, подарки, зоотовары.

Работает ли с кассой?

Можно подключить чеки из кассы через POS-ключ, а можно отмечать покупки вручную или сканером.

Если у меня несколько магазинов?

Для нескольких точек есть тариф Pro: общая база, аналитика по каждой точке и общий обмен данными между компьютерами.
