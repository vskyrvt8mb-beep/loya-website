Loya — сайт 2.24: как загрузить на GitHub

1. Распакуйте архив. Откройте папку Loya_site_2_24.
2. На GitHub: репозиторий loya-website → Add file → Upload files.
3. Выделите в папке Loya_site_2_24 ВСЁ (Ctrl+A) — и папки, и файлы — и ПЕРЕТАЩИТЕ мышкой в окно GitHub.
4. Проверьте, что в списке видны пути с папками (например  api/_admin_ed.js,  ru/index.html).
5. Commit changes. Vercel обновит сайт через 1–2 минуты.
6. Проверка: https://loya-loyalty.com/api/health → "siteVersion":"2.24.0".

Новых таблиц в Supabase не нужно (если schema_2_23.sql уже запускали).

Этот файл загружать не обязательно. В корне репозитория после прошлой загрузки лежит
файл с «кракозябрами» в названии (.txt) — это прошлая инструкция, его можно удалить.
