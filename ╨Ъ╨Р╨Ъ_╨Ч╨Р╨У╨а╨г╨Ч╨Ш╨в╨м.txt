Loya — сайт 2.23: как загрузить на GitHub

1. Распакуйте архив. Откройте папку Loya_site_2_23.
2. На GitHub: репозиторий loya-website → Add file → Upload files.
3. Выделите в папке Loya_site_2_23 ВСЁ (Ctrl+A) — и папки, и файлы — и ПЕРЕТАЩИТЕ мышкой в окно GitHub.
   Не выбирайте файлы через кнопку «choose your files»: так теряются папки (api/, uk/, ru/, sk/ …).
4. Проверьте, что в списке загрузки видны пути с папками (например  api/_clientCfg.js,  uk/cafe/index.html).
5. Commit changes. Vercel сам обновит сайт через 1–2 минуты.
6. Проверка: откройте https://loya-loyalty.com/api/health — там должно быть "siteVersion":"2.23.0".

ОДИН РАЗ в Supabase (SQL Editor → New query → вставить → Run):
   содержимое файла schema_2_23.sql (из этой же папки).
   Он добавляет колонку «точка» к онлайн-регистрациям — для отдельных страниц у каждой точки.
   Если ещё не запускали schema_2_19.sql и schema_2_20.sql — запустите и их (они уже лежат в репозитории).
   Без schema_2_23.sql сайт всё равно работает, просто регистрации по ссылке не разделяются по точкам.

Telegram-уведомления о новых подписках:
   Админка → вкладка «Сервис» → блок «🚀 Готовность к запуску» (нажмите, чтобы раскрыть) → «📲 Подключить Telegram» → в открывшемся боте нажмите «Запустить» (Start).
   Через пару секунд в админке появится «подключено», и бот сразу пришлёт пробное сообщение.
