Loya — сайт 2.22: как загрузить на GitHub

1. Распакуйте архив. Откройте папку Loya_site_2_22.
2. На GitHub: репозиторий loya-website → Add file → Upload files.
3. Выделите в папке Loya_site_2_22 ВСЁ (Ctrl+A) — и папки, и файлы — и ПЕРЕТАЩИТЕ мышкой в окно GitHub.
   Не выбирайте файлы через кнопку «choose your files»: так теряются папки (api/, uk/, ru/, sk/ …),
   и файлы ложатся в корень — именно это сломало главную страницу 16.10.
4. Проверьте, что в списке загрузки видны пути с папками (например  api/_x_health.js,  uk/cafe/index.html).
5. Commit changes. Vercel сам обновит сайт через 1–2 минуты.

Этот файл (КАК_ЗАГРУЗИТЬ.txt) загружать не нужно — можно, он ничему не мешает.

После этого удалите из корня репозитория лишние файлы, которые попали туда при прошлой загрузке:
   index (1).html … index (47).html,  _x_book_page.js,  _x_fb_page.js,  _x_online_page.js,
   build-seo.js,  en.js,  ru.js,  sk.js,  uk.js,  index.template.html
Быстрее всего: на странице репозитория нажмите клавишу «.» (точка) — откроется github.dev,
выделите эти файлы (Ctrl+клик), Delete, затем слева «Source Control» → Commit & Push.
Внимание: НЕ удаляйте файлы с такими же именами внутри папок (api/, i18n/, scripts/) и корневой index.html.
